# Balance Club

Статический адаптивный сайт Balance Club. Главная и «О нас» сохраняют ранее реализованные макеты. Остальные страницы сверстаны без анимации по 20 макетам на странице Figma «UI kit • Balance club». Дополнительно создан раздел согласия на обработку персональных данных.

## Локальный просмотр

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Сборка и внешние зависимости не нужны.

## Публикация

Сайт: https://kruglovadarias-cpu.github.io/balance-club/

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Структура

- `index.html` — семантическая разметка всех секций.
- `styles.css` — сетка, адаптивность, токены и локальный Involve.
- `ui-refinements.css` — правки из браузерных аннотаций: мобильный первый экран, кнопки и подчёркивание ссылок.
- Лента партнёров статична, без стрелок и пагинации.
- `app.js` — меню, окна связи, поиск, просмотр интерьера.
- `sliders.js` — слайдеры предложений, услуг, интерьера, отзывов и специалистов; стрелки, клавиатура, нативная прокрутка.
- `COPY_REVIEW.md` — заключительная редакторская проверка текста макета.
- `assets/` — локальные изображения и SVG из Figma, шрифт Involve.

## Что ещё требует подключения или согласования

- Серверная отправка заявок и подписка: пока кнопки открывают реальные способы связи, а подписка формирует письмо администратору. Статический GitHub Pages не обрабатывает заявки на сервере.
- Меню главной и «О нас» ведёт на новые страницы. Документы без предоставленного PDF запрашиваются у администратора.
- Страница `consent.html` создана без текста по просьбе владельца; пункт меню расположен перед политикой конфиденциальности.
- Формы новых страниц проверяют обязательные поля и согласие, затем открывают письмо администратору. Серверной отправки нет.
- По просьбе владельца все категории внутри каталога временно показывают одинаковый набор карточек; все карточки услуг ведут на страницу «Релатокс». Для специалистов без отдельного макета доступен запрос администратору.
- Реальные отзывы и соответствие фотографий именам специалистов: сейчас перенесены повторяющиеся демонстрационные подписи из нового макета. Замечания и необходимые данные перечислены в COPY_REVIEW.md.
- Статистика, условия акции 28.11.2026, документы и фактические сведения сохранены из макета и требуют проверки владельцем перед использованием как окончательного сайта.
- Подтвердить адреса социальных сетей: неизвестные профили не выдуманы.

Изображения и шрифты предоставлены в проекте пользователя; репозиторий не предоставляет отдельной лицензии на их повторное использование.

## Внутренние страницы

- `catalog.html`, `injections.html`, `service.html`, `prices.html` — услуги и цены.
- `specialists.html`, `specialist.html` — специалисты.
- `blog.html`, `article.html` — публикации.
- `offers.html`, `offer.html`, `subscriptions.html`, `subscription.html`, `certificates.html` — предложения.
- `patients.html`, `documents.html`, `payment.html`, `details.html`, `legal.html`, `consent.html`, `privacy.html` — Инфо с общим боковым меню.
- `contacts.html` — контакты и карта.
- `pages.css`, `page-artwork.css`, `pages.js` — стили, геометрия ресурсов Figma и поведение новых страниц без анимации.
- `scripts/pages-assets.json` — соответствия изображений узлам макетов.
