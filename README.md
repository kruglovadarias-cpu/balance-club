# Balance Club

Статическая адаптивная главная страница по исправленному макету Figma `493:9310` на странице «Правки по макету сайта». Анимации намеренно не добавлены.

## Локальный просмотр

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Сборка и внешние зависимости не нужны.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Структура

- `index.html` — семантическая разметка всех секций.
- `styles.css` — сетка, адаптивность, токены и локальный Involve.
- `ui-refinements.css` — правки из браузерных аннотаций: мобильный первый экран, кнопки и подчёркивание ссылок.
- Лента партнёров статична, без стрелок и пагинации.
- `app.js` — меню, окна связи, поиск, просмотр интерьера.
- `sliders.js` — слайдеры предложений, услуг, интерьера, отзывов и специалистов; стрелки, клавиатура, нативная прокрутка.
- `COPY_REVIEW.md` — заключительная редакторская проверка текста макета.
- `assets/` — локальные изображения и SVG из Figma, шрифт Involve.

## Что ещё требует подключения или согласования

- Серверная отправка заявок и подписка: пока кнопки открывают реальные способы связи, а подписка формирует письмо администратору. Статический GitHub Pages не обрабатывает заявки на сервере.
- Прочие страницы ещё не сверстаны: навигация главной ведёт к соответствующим разделам, документы запрашиваются у администратора.
- Реальные отзывы и соответствие фотографий именам специалистов: сейчас перенесены повторяющиеся демонстрационные подписи из нового макета. Замечания и необходимые данные перечислены в COPY_REVIEW.md.
- Статистика, условия акции 28.11.2026, документы и фактические сведения сохранены из макета и требуют проверки владельцем перед использованием как окончательного сайта.
- Подтвердить адреса социальных сетей: неизвестные профили не выдуманы.

Изображения и шрифты предоставлены в проекте пользователя; репозиторий не предоставляет отдельной лицензии на их повторное использование.
