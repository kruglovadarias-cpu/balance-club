# Balance Club

Статическая адаптивная главная страница по исправленному макету Figma `430:5456` на странице UI kit. Анимации намеренно не добавлены.

## Локальный просмотр

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Сборка и внешние зависимости не нужны.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Структура

- `index.html` — семантическая разметка всех секций.
- `styles.css` — сетка, адаптивность, токены и локальный Involve.
- `app.js` — меню, окна связи, поиск, просмотр интерьера.
- `assets/` — локальные изображения и SVG из Figma, шрифт Involve.

## Что ещё требует подключения или согласования

- Серверная отправка заявок и подписка: пока кнопки открывают реальные способы связи, а подписка формирует письмо администратору. Статический GitHub Pages не обрабатывает заявки на сервере.
- Прочие страницы ещё не сверстаны: навигация главной ведёт к соответствующим разделам, документы запрашиваются у администратора.
- Реальные отзывы и соответствие фотографий именам специалистов: до подтверждения отсутствуют вымышленные цитаты и авторства, фотографии подписаны нейтрально.
- Статистика, условия архивной акции, документы и фактические сведения сохранены из макета и требуют проверки владельцем перед использованием как окончательного сайта.
- Подтвердить адреса социальных сетей: неизвестные профили не выдуманы.

Изображения и шрифты предоставлены в проекте пользователя; репозиторий не предоставляет отдельной лицензии на их повторное использование.
